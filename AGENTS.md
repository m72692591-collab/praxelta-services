# ПРАКСЕЛЬТА: правила работы с публичным репозиторием

## Граница данных

- Репозиторий содержит только публичные страницы, обезличенные примеры, юридические документы и безопасные статические ресурсы.
- Реальные контакты потенциальных клиентов, переписка, согласия, внутренние заметки, cookies, токены, ключи и выгрузки кабинетов здесь запрещены.
- Закрытые операционные данные хранятся только в соседнем локальном проекте `praxelta-ops`.

## Публикация и отправка

- Ветка `main` не меняется и сайт не публикуется без пройденного migration deployment gate и отдельного подтверждения владельца.
- Подготовленный текст не считается отправленным сообщением. Отправку подтверждает только квитанция провайдера.
- Холодная автоматическая рассылка запрещена. Любая отправка требует доказанного согласия, проверки suppression list, одобрения получателя и текста владельцем, тестовой отправки владельцу и соблюдения лимита кампании.

## Тексты и цены

- В русскоязычном публичном тексте бренд пишется только `ПРАКСЕЛЬТА`.
- Публичные обещания описывают работу и результат, а не гарантированное число обращений или продаж.
- Источник цен — `pricing.json`. Страницы с тарифами создаются командой `python scripts/render_local_growth.py`.
- Перед публикацией обязателен humanity gate: текст должен быть понятным, точным, естественным, конкретным и адресным.

## Проверка

- Запуск: `python scripts/check_public_site.py`.
- PDF создаются командой `python scripts/generate_pdfs.py` после установки зависимостей из `requirements-dev.txt`.
- В публичном Git не должно быть реальных списков лидов или секретов даже в истории тестов.
