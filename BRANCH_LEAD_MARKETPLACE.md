# Ветка `agent/praxelta-lead-marketplace`

Эта ветка предназначена для самостоятельного направления **ПРАКСЕЛЬТА Маркет**:

- продвижение широкого перечня локальных услуг;
- регистрация и оформление ПРАКСЕЛЬТЫ на разрешённых площадках;
- создание собственных источников входящих заявок;
- подключение и проверка мастеров;
- последовательное или явно согласованное распределение заявок;
- плата за квалифицированные заявки, подписка и будущая success-fee модель;
- подключение поставщиков запчастей, материалов и оборудования;
- партнёрское вознаграждение по подтверждённым заказам;
- CRM, телефония, Telegram-боты, реклама, контент и аналитика;
- юридические, consent, safety, budget и payment gates.

## Один промпт для запуска Codex

Скопируй в Codex целиком только этот файл:

[`codex/PRAXELTA_CODEX_ONE_PROMPT_FULL_AUTOMATION_RU.md`](codex/PRAXELTA_CODEX_ONE_PROMPT_FULL_AUTOMATION_RU.md)

Это канонический единый мастер-промпт. Он охватывает:

- сантехнику;
- электрику;
- ремонт бытовой техники;
- отопление и бытовые котлы;
- кондиционеры;
- мастер на час;
- окна и двери;
- клининг;
- ремонт жилья;
- компьютеры;
- автоуслуги;
- обслуживание малого бизнеса;
- динамическое подключение новых категорий;
- регистрацию площадок;
- получение лидов;
- поиск и onboarding мастеров;
- поставщиков;
- полную операционную автоматизацию с обязательными human gates для OTP, CAPTCHA, документов, бюджетов и юридических решений.

## Справочные документы

- [`docs/PRAXELTA_LEAD_MARKETPLACE_PROJECT_RU.md`](docs/PRAXELTA_LEAD_MARKETPLACE_PROJECT_RU.md) — продуктовая спецификация;

## Статус

`PRELAUNCH / MULTI-CATEGORY / SANDBOX FIRST / NO PRODUCTION SIDE EFFECTS`

До отдельного подтверждения владельца запрещены:

- публикация ветки в GitHub Pages;
- merge в `main`;
- реальная массовая рассылка;
- автоматическое принятие юридических оферт;
- обход OTP или CAPTCHA;
- расходование рекламного бюджета без approval;
- загрузка реальных клиентских контактов в публичный Git;
- передача реальных заявок без согласия и approval;
- приём клиентских денег за мастеров или поставщиков;
- начисление реального процента до legal/tax gate;
- перепродажа запчастей от имени ПРАКСЕЛЬТЫ.

Текущий юридический режим считать `NPD_PRELAUNCH`, пока не подтверждена иная организационная и налоговая конструкция.
