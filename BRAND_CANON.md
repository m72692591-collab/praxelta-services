# Канонический бренд МАЭСТРО

## Статус

```text
CANONICAL_PUBLIC: МАЭСТРО / MAESTRO
REJECTED_COMMON_NAME: Поток / Potok
```

МАЭСТРО — отдельный коммерческий проект владельца. Он не является частью ANIMA TACTUS и не должен смешивать с ним продукты, аудиторию, данные, рекламу или финансовую модель.

## Обязательные правила

1. В новых заголовках, описании репозитория, сайте, коммерческих предложениях, объявлениях и документах публичный бренд — `МАЭСТРО` / `MAESTRO`. `ПРАКСЕЛЬТА` / `PRAXELTA` сохраняется в именах репозиториев, путях, коде, скриптах генерации, юридически оформленных материалах и истории (класс `FILE_OR_BRANCH_NAME` или `LEGACY_COMPATIBILITY_ONLY`). Перевод существующих страниц — отдельными PR по карте миграции, без массовой замены.
2. Распространённое старое название запрещено как активный бренд, продукт, тариф или площадка.
3. Историческое упоминание допустимо только с маркировкой `LEGACY_COMPATIBILITY_ONLY`.
4. Репозиторий `potok-services` является только старым адресом-перенаправлением и не получает новую функциональность.
5. Массовая автоматическая замена по бинарным файлам и авторским материалам запрещена.
6. Публичное действие считается выполненным только по фактической ссылке, ID публикации или иному проверяемому доказательству.
7. При бюджете 0 ₽ любая неизвестная стоимость блокирует действие.

## История решения

До 01.11.2026 правило 1 требовало только `ПРАКСЕЛЬТА`, что противоречило статусу `CANONICAL_PUBLIC: МАЭСТРО` в этом же файле и решению владельца о публичном бренде МАЭСТРО. Противоречие устранено 01.11.2026.

## Миграция старых упоминаний

Каждое найденное упоминание сначала классифицируется:

- `ACTIVE_VIOLATION` — новый публичный текст под старым брендом; исправить на МАЭСТРО в отдельном PR;
- `LEGACY_COMPATIBILITY_ONLY` — оставить с явной маркировкой;
- `HISTORICAL_EVIDENCE` — сохранить без переписывания истории;
- `FILE_OR_BRANCH_NAME` — не переименовывать автоматически, создать карту миграции.
