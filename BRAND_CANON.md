# Канонический бренд ПРАКСЕЛЬТА

## Статус

```text
CANONICAL_PUBLIC: ПРАКСЕЛЬТА / PRAXELTA
REJECTED_COMMON_NAME: Поток / Potok
```

ПРАКСЕЛЬТА — отдельный коммерческий проект владельца. Он не является частью ANIMA TACTUS и не должен смешивать с ним продукты, аудиторию, данные, рекламу или финансовую модель.

## Обязательные правила

1. В заголовках, описании репозитория, сайте, коммерческих предложениях, объявлениях, документах и новых ветках используется только `ПРАКСЕЛЬТА` или `PRAXELTA`.
2. Распространённое старое название запрещено как активный бренд, продукт, тариф или площадка.
3. Историческое упоминание допустимо только с маркировкой `LEGACY_COMPATIBILITY_ONLY`.
4. Репозиторий `potok-services` является только старым адресом-перенаправлением и не получает новую функциональность.
5. Массовая автоматическая замена по бинарным файлам и авторским материалам запрещена.
6. Публичное действие считается выполненным только по фактической ссылке, ID публикации или иному проверяемому доказательству.
7. При бюджете 0 ₽ любая неизвестная стоимость блокирует действие.

## Миграция старых упоминаний

Каждое найденное упоминание сначала классифицируется:

- `ACTIVE_VIOLATION` — исправить на ПРАКСЕЛЬТА;
- `LEGACY_COMPATIBILITY_ONLY` — оставить с явной маркировкой;
- `HISTORICAL_EVIDENCE` — сохранить без переписывания истории;
- `FILE_OR_BRANCH_NAME` — не переименовывать автоматически, создать карту миграции.
