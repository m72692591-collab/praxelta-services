# ПРАКСЕЛЬТА

ПРАКСЕЛЬТА — действующее уникальное наименование проекта по управляемому продвижению локальных услуг, учёту обращений и развитию проверенной сети исполнителей.

Старый репозиторий совместимости используется только для перенаправления прежних ссылок и не является самостоятельным брендом или отдельным продуктом.
