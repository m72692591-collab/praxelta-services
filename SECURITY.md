# Безопасность ПРАКСЕЛЬТА

Этот репозиторий содержит только статические публичные страницы.

## Никогда не публиковать

- пароли и одноразовые коды;
- Password 1 / Password 2, API-ключи и подписи Robokassa;
- номера банковских карт, CVV/CVC и полные реквизиты счетов;
- cookies, токены сессий и резервные коды 2FA;
- персональные данные клиентов и выгрузки кабинетов Ozon/Wildberries.

## Платежи

Платёжные данные принимаются только на официальной защищённой странице Robokassa. Секретная подпись формируется только в защищённом серверном контуре или средствами Robokassa; GitHub Pages не используется для хранения секретов и формирования подписи.

## Изменения сайта

- перед публикацией проверять ссылки, цены, реквизиты и правовые страницы;
- не добавлять формы, сторонние скрипты, пиксели и загрузку файлов без отдельного аудита;
- внешние ссылки открывать с `rel="noopener noreferrer"`, когда используется новая вкладка;
- включить 2FA для GitHub и Robokassa и ограничить доступ минимально необходимыми правами;
- хранить резервные коды только офлайн, не в репозитории.
