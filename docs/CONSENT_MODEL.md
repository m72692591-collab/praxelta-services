# Модель согласия

Согласие на обработку, согласие на передачу мастеру и согласие на маркетинг — три разных решения.

Для заявки фиксируются версия текста, цель, категории данных, способ подтверждения, канал, время и предел передачи:

- одному мастеру;
- последовательно по одному;
- максимум трём мастерам;
- никому до самостоятельного выбора клиента.

Отзыв согласия до передачи прекращает маршрутизацию. Мастер не получает права использовать контакт для посторонней рекламы. Каждое фактическое раскрытие должно иметь получателя, время и основание.
