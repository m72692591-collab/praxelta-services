# Ежедневный sandbox-цикл

Команда закрытого контура:

```powershell
.\.venv\Scripts\python.exe scripts\run_daily_automation.py
```

`SchedulerAgent` запускает 15 специализированных агентов и пишет один идемпотентный отчёт. Текущая версия безопасно читает состояние, считает очереди и готовность и не делает внешних вызовов. `external_side_effects` обязан оставаться равным нулю, пока production flags выключены.

Проверяемые задачи: статусы площадок, human actions, категории, города, кампании, мастера, квалификация, маршрутизация, поставщики, качество, compliance, аналитика и humanity. Автоматический поиск, публикация и рассылка не симулируются как выполненные.
