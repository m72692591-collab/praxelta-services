# План внедрения направления локального продвижения

## Критерий готовности

В рабочей ветке есть отдельный публичный продукт за 7 900 ₽, городские и коммерческие материалы, единый источник цен, проверяемая печатная версия и локальная закрытая система учёта, где отправка невозможна без согласия и одобрения. Публикация и реальные сообщения не входят в этот этап.

## Публичный контур

1. Добавить `local-growth.html`, обезличенный пример, полное коммерческое предложение, короткую версию и лид-магнит.
2. Создать шесть содержательных городских страниц без выдуманной статистики.
3. Хранить цены в `pricing.json`, а тарифные блоки генерировать из шаблонов.
4. Обновить главную, sitemap, условия заказа, безопасность и документацию.
5. Добавить проверку ссылок, canonical, CSP, цен, бренда, секретов и запрещённых контактов.
6. Сгенерировать и визуально проверить PDF коммерческих страниц.

## Закрытый контур

1. Создать рядом локальный проект `praxelta-ops` на Python, FastAPI и SQLite.
2. Реализовать модели потенциального клиента, согласия, кампании, черновика, отправки, suppression list и аудита.
3. Сделать dry-run режимом по умолчанию; наружу работают только mock и ручной экспорт.
4. Проверять согласие, suppression, owner approval, лимит кампании, тест владельцу и idempotency key до вызова провайдера.
5. Добавить простую локальную панель, синтетические данные, тесты, безопасный импорт и резервное копирование.

## Внешние gate

- Draft PR разрешён; merge и публикация — только после отдельного подтверждения.
- Создание внешнего приватного репозитория для `praxelta-ops` — только после отдельного подтверждения.
- Реальная реклама, подписки, телефония, бот и отправка сообщений остаются выключенными до настройки разрешённого провайдера и прохождения всех gate.
