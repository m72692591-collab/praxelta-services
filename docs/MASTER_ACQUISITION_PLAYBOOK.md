# Набор мастеров

Разрешённый поток: публичная страница, рекомендации, магазины и поставщики, учебные центры, сервисные компании, профессиональные сообщества с правилами размещения, официальные каталоги и ограниченное ручное исследование публичных бизнес-профилей.

Контакт добавляется только с источником и датой проверки. Публичный контакт не равен согласию на рекламу. Система может подготовить персональный черновик, но `REAL_SEND=OFF` и переход `NEW_PROSPECT → CONTACT_ALLOWED` требует записанного основания.

Этапы onboarding реализованы без пропусков: `NEW_PROSPECT → CONTACT_ALLOWED → INVITED → APPLICATION_STARTED → CONTACT_VERIFIED → DOCUMENTS_PENDING → REVIEW → TEST_MODE → ACTIVE → PAUSED/SUSPENDED/TERMINATED`.

Статус «проверен» всегда расшифровывает фактически проверенный слой. Первые реальные заявки — только под ручным контролем.
