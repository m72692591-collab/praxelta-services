# ПРАКСЕЛЬТА Ремонт V8 — UX-потоки

Статус: `IMPLEMENTED_AS_STANDALONE_PROTOTYPE`  
Публичный статус: `CONCEPT_NOT_PRODUCTION`

## Клиент

```text
Главная → новая заявка → предварительная оценка → прозрачная деталь
→ capability-gated checkout → split-статусы → активный заказ / спор
```

Цена до диагностики показана диапазоном. Изменение согласованной сметы хранит старую сумму, новую сумму, причину и автора. Событие frontend не меняет банковский статус.

## Мастер и поставщик

```text
кабинет мастера → тарифный snapshot → ожидаемая выплата → точная причина блокировки
→ резерв поставщика → конкретный SKU → одноразовый QR только после свежего backend-confirmation
```

## Администратор

```text
capability matrix → webhook health → split legs → reconciliation mismatch queue
```

Секреты и полные банковские реквизиты не отображаются. При `unknown`, `stale`, `partial` или `blocked` финансовые действия закрыты.

## Системные состояния

Интерактивная панель State Lab демонстрирует `loading`, `empty`, `error`, `blocked`, `offline`, `stale`, `partial`, `refund` и `dispute`. Каждое состояние содержит причину либо следующий безопасный шаг; цвет не используется без текста.
