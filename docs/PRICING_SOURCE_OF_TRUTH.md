# Единый источник цен

Публичные цены хранятся в `pricing.json`. Страницы направления создаются из `templates/local-growth/*.html` командой:

```powershell
python scripts/render_local_growth.py
```

Проверка `python scripts/check_public_site.py` сравнивает все помеченные цены с конфигом. Ручная правка тарифных сумм в сгенерированных страницах не допускается.

Сторонние подписки и рекламный бюджет не входят в цены ПРАКСЕЛЬТЫ. Зачёт экспресс-разбора в первый месяц ежемесячного тарифа действует только тогда, когда это прямо записано в индивидуальном заказе.
