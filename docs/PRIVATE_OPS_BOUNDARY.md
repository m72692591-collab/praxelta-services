# Граница закрытого операционного контура

`praxelta-services` — публичная витрина. `praxelta-ops` — отдельная локальная система. Они не используют одну базу и не публикуются одним процессом.

В публичном репозитории разрешены только синтетические примеры без реальных контактов. Реальные потенциальные клиенты могут появиться только в локальной базе `praxelta-ops`, если для записи есть источник и законное основание. Экспорт такой базы в публичный Git запрещён.

`praxelta-ops` не получает секреты из файлов публичного сайта. Его `.env`, база SQLite, резервные копии и выгрузки исключаются из Git. Создание внешнего приватного репозитория требует отдельного решения владельца.
